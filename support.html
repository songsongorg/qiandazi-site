FAQ

How do I add an item? （如何添加事项？）

Open the Items tab and tap the + button. Choose a type — subscription, domain, deposit, card activity, or custom — fill in the name, amount, currency and cycle, then save. Qiandazi will compute the next renewal date and schedule reminders for you.

打开"清单"页，点右下角 + 按钮，选择事项类型（订阅 / 域名 / 存款 / 信用卡活动 / 自定义），填写名称、金额、币种和周期后保存。应用会自动算出下次续费日期并安排提醒。

How do I mark something as renewed? （如何标记续费？）

On the "Upcoming" timeline, tap the item due for renewal and choose Renewed. Confirm the amount — it will be recorded as a ledger entry automatically, and the next cycle starts. If you don't want a ledger entry, use the "Complete without ledger" option.

在"接下来"时间线上点击要续费的事项，选择已续费，确认金额后会自动生成一条记账流水，并开启下一周期。如不想记账，可选择"不记账，直接完成"。

How do backup and restore work? （备份与恢复怎么用？）

Go to Settings → Backup. Export saves all your data as a JSON file you can keep anywhere. Import restores from a JSON backup — before importing, the app automatically writes a safety backup so nothing is lost. The app also keeps automatic local backups.

进入"设置 → 备份"：导出会把全部数据存为 JSON 文件（您自行保管）；导入从 JSON 备份恢复——导入前应用会自动写一份安全备份，防止数据丢失。应用也会定期自动备份。

I'm not receiving reminders. （收不到提醒怎么办？）

First check that notifications are allowed for Qiandazi in your system settings (Settings → Notifications → Qiandazi). Then open the app's Reminder Health page (in Settings), which shows whether reminders are scheduled correctly and helps diagnose permission problems.

先到系统设置 → 通知 → 钱搭子确认已允许通知。然后打开应用内的提醒健康页（设置中），它会显示提醒是否正确排期，并帮助诊断权限问题。

A domain lookup returns nothing. （域名查询查不到怎么办？）

Qiandazi queries public RDAP and WHOIS services. Some TLDs (e.g. .cn, .io, .me, .co, .jp, .de, .hk) have limited or no public WHOIS data. In that case you can enter the expiry date manually — reminders work exactly the same. Lookups only run when you tap "Query", so no data is sent without your action.

应用通过公开的 RDAP / WHOIS 服务查询。某些后缀（如 .cn、.io、.me、.co、.jp、.de、.hk）公开数据有限或没有，这种情况下可以手动填写到期日，提醒功能完全一样。查询只在您点击"查询"时发起。
